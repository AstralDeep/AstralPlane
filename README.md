# AstralPlane

AstralPlane now lives in AstralDeep under [`plane/`](https://github.com/AstralDeep/AstralDeep/tree/main/plane), with its full history, and this repository is archived.

Issues and pull requests go to [AstralDeep](https://github.com/AstralDeep/AstralDeep/issues) with the `plane` label. The open issues here moved there, and the old issue links redirect.

Older Deep commits pin this repository as a submodule, and those pins still check out from this archive. The package name, `astralplane`, is unchanged.
